Title: 誕生日のパラドックスから考察する、個人ブログURLに必要なランダムビット数
Date: 2020-05-07



# tl;dr

-   ブログのURLにランダム値を使うとして、必要なビット数は何桁だろうか
-   ハッシュ衝突の問題は「誕生日のパラドックス」と同じ状況設定
-   数学的な裏付けの元で、ランダムビットを28桁確保すれば十分


# Intro

「[個人ブログのパーマリンクに関する最適戦略について](https://s.conao3.com/blog/2020/0bc44c)」において、

-   `{{base-url}}` / blog / `{{year}}` / `{{random}}`

というURLをこのブログに使うことに決めました。しかし、 `{{random}}` はどれだけのビット数を使い、どのようなフォーマットを使うべきでしょうか。

幸い、 `{{year}}` を入れているので、「永遠」を考える必要はありません。
せいぜい「1年」でどれだけの記事を書くのかを見積れば良いことになります。

毎日、1記事を書いたとして <span class="math" data-tex="MzY1"></span> 記事、多めに見積もって <span class="math" data-tex="NDAw"></span> 記事とします。
さらに毎日、 <span class="math" data-tex="NQ=="></span> 記事書くことを上限と仮定すると <span class="math" data-tex="NSBcdGltZXMgNDAwID0gMjAwMA=="></span> 記事となり、せいぜい <span class="math" data-tex="MjAwMA=="></span> 記事がある場合に必要なランダムビット数を求めたいと思います。


# 誕生日のパラドックス

「[誕生日のパラドックス - Wikipedia](https://ja.wikipedia.org/wiki/%E8%AA%95%E7%94%9F%E6%97%A5%E3%81%AE%E3%83%91%E3%83%A9%E3%83%89%E3%83%83%E3%82%AF%E3%82%B9)」より、

> 誕生日のパラドックス（たんじょうびのパラドックス、英: birthday paradox）とは「何人集まれば、その中に誕生日が同一の2人（以上）がいる確率が、50%を超えるか?」という問題から生じるパラドックスである。鳩の巣原理より、366人（閏日も考えるなら367人）集まれば確率は100%となるが、しかしその5分の1に満たない70人しか集まらなくても確率は99.9%を超え、50%を超えるのに必要なのはわずか23人である。
> 
> 誕生日のパラドックスは論理的な矛盾に基づいているという意味でのパラドックスではなく、結果が一般的な直感と反しているという意味でのパラドックスである。

Wikipediaでも計算してありますが、ここでも計算しておきます。

きちんと問題として整理すると以下のようになります。

> Aさんを含め、n人がいる。一年を365日とし、誕生日は全ての日で等確率とする。
> 
> 1.  Aさんと同じ誕生日の人が存在する確率 <span class="math" data-tex="UF8x"></span>
> 2.  同じ誕生日の人が存在する確率 <span class="math" data-tex="UF8y"></span>
> 3.  <span class="math" data-tex="UF8x"></span> と <span class="math" data-tex="UF8y"></span> が <span class="math" data-tex="NTA="></span> %を超えるのにそれぞれ必要な人数 <span class="math" data-tex="bl9cdGV4dHttaW4xfQ=="></span>, <span class="math" data-tex="bl9cdGV4dHttaW4yfQ=="></span>

1.  Aさんと同じ誕生日の人が存在する確率 <span class="math" data-tex="UF8x"></span>
    
    余事象で求める。
    
    Aさん以外の人は <span class="math" data-tex="XGZyYWN7MzY0fXszNjV9"></span> の確率でAさんの誕生日と衝突しない。
    Aさん以外の人は <span class="math" data-tex="bi0x"></span> 人存在するので、
    
    <span class="math display" data-tex="IFBfMSA9IDEgLSBccXR5KFxmcmFjezM2NH17MzY1fSlee24tMX0g"></span>

2.  同じ誕生日の人が存在する確率 <span class="math" data-tex="UF8y"></span>
    
    余事象で求める。
    
    n人の誕生日が異なる確率は
    <span class="math display" data-tex="IFxmcmFjezM2NH17MzY1fVxjZG90XGZyYWN7MzYzfXszNjV9XGNkb3RcZnJhY3szNjJ9ezM2NX1cY2RvdHNcZnJhY3szNjUtKG4tMSl9ezM2NX0gPSBcZnJhY3t7fV97MzY0fVxtYXRocm17UH1fe24tMX19ezM2NV57bi0xfX0gPSBcZnJhY3t7fV97MzY1fVxtYXRocm17UH1fbn17MzY1Xm59"></span>
    
    よって
    <span class="math display" data-tex="IFBfMiA9IDEgLSBcZnJhY3t7fV97MzY1fVxtYXRocm17UH1fbn17MzY1Xm59IA=="></span>

3.  <span class="math" data-tex="UF8x"></span> と <span class="math" data-tex="UF8y"></span> が <span class="math" data-tex="NTA="></span> %を超えるのにそれぞれ必要な人数 <span class="math" data-tex="bl9cdGV4dHttaW4xfQ=="></span>, <span class="math" data-tex="bl9cdGV4dHttaW4yfQ=="></span>
    
    <span class="math" data-tex="bl9cdGV4dHttaW4xfQ=="></span> については計算できる。
    
    <div class="math display" data-tex="XGJlZ2lue2FsaWduZWR9CiAgICAgUF8xID0gMSAtIFxxdHkoXGZyYWN7MzY0fXszNjV9KV57bi0xfSAmPiAwLjUgXFwKICAgICAwLjUgJj4gXHF0eShcZnJhY3szNjR9ezM2NX0pXntuLTF9IFxcCiAgICAgXGxvZ18yKDAuNSkgJj4gKG4tMSlcbG9nXzJccXR5KFxmcmFjezM2NH17MzY1fSkgXFwKICAgICAtMSAmPiAobi0xKSgtMC4wMDM5NTgpIFxcCiAgICAgMjUzLjY1ICY8IG4KICAgXGVuZHthbGlnbmVkfQ=="></div>
    
    よって <span class="math" data-tex="bl9cdGV4dHttaW4xfT0yNTQ="></span> となる。
    
    <span class="math" data-tex="bl9cdGV4dHttaW4yfQ=="></span> については面倒なので、Pythonを用いて図示する。
    
        import matplotlib.pyplot as plt
        import numpy as np
        
        memo = np.full(400, -1.0)
        def NPn (n):
            """
            余事象の確率
            n人の誕生日が異なる確率
            """
            if n == 0 or n == 1:
                memo[0] = 1
                return memo[0]
            elif n >= 366:
                return 1;
            elif memo[n] != -1:
                return memo[n]
            else:
                p = NPn(n-1) * ((365-(n-1))/365.0)
                memo[n] = p
                return memo[n]
        
        def Pn (n):
            """
            n人のうち、2人以上誕生日が同じ確率
            """
            return 1 - NPn(n)
        
        n = 70
        with plt.style.context(('science-transparent')):
            y = [Pn(i) for i in range(n)]
            plt.plot(y)
        
            plt.xlabel('n')
            plt.ylabel('P_n')
        
            plt.axhline(0.5, color='C1')
            n_min2 = np.searchsorted(y, 0.5)
            plt.annotate('({}, {:.2f})'.format(n_min2, y[n_min2]),
                         (n_min2, y[n_min2]), (n_min2-15, 0.8),
                         arrowprops = dict(arrowstyle='-|>', mutation_scale=20))
        
            plt.show()

直感との乖離の理由は「自分と同じ誕生日の人が存在する確率」と「同じ誕生日の組が存在する確率」を混同してしまうからです。


# ランダム値の衝突

今回問題にしているようなランダム値の衝突については、
「あるひとつのランダム値が衝突する事象」ではなく、「どれでもいいのでランダム値が衝突する事象」を考える必要があるので、
まさに誕生日のパラドックスと同じ状況設定となります。
